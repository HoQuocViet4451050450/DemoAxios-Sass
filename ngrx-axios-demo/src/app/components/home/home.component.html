Cài đặt Axios/Sass & NgRX

Công việc Bước thực hiện
Cài đặt Axios 1. Đảm bảo bạn sử dụng Angular CLI phiên bản 16.
2. Chạy lệnh npm install axios@16 để cài đặt Axios.
3. Sử dụng Axios trong Effects để gửi yêu cầu HTTP.
Cài đặt Sass 1. Đảm bảo bạn sử dụng Angular CLI phiên bản 16.
2. Chạy lệnh npm install sass --save-dev Để cài đặt Sass.
3. Đổi cấu hình style của angular.json thành "styles": [ "src/styles.scss" ] 4. Đổi phần mở rộng của các tệp CSS thành .scss (ví dụ: app.component.scss).
5. Angular sẽ tự động biên dịch Sass thành CSS khi chạy ứng dụng.
Cài đặt NgRx 1. Đảm bảo bạn sử dụng Angular CLI phiên bản 16.
2. Chạy lệnh npm install @ngrx/store@16 @ngrx/effects@16 @ngrx/store-devtools@16 để cài đặt NgRx.
3. Tạo reducer và actions trong thư mục store để quản lý trạng thái.
4. Cấu hình StoreModule trong AppModule để kết nối reducer vào ứng dụng.
5. Sử dụng Store trong các component để truy xuất và thay đổi trạng thái.
6. Cài đặt Redux DevTools Extension trong trình duyệt (Chrome).
7. Cấu hình Redux DevTools trong App.module.ts
